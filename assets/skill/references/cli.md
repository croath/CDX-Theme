# CLI (`/path/to/cdxthemex`)

Thin CLI over shared library **`cdx-theme-core`**. Invoke as **`/path/to/cdxthemex`**; saved probes as **`/path/to/run.sh <name>`**. Resolve placeholders in repo `AGENTS.md`.

Pack, unpack, and apply **multi-app** portable theme packages (`.cdxtheme`).

| Format | `format` field | Extension |
|--------|----------------|-----------|
| **CDXTheme** | `cdxtheme` | `.cdxtheme` |

Legacy single-file formats (`.codex-theme` with top-level `manifest` + `css`) are **not** supported.

### `theme pack`

**`theme-dir`** is a skill variable: the directory of one theme (`theme.json` + partials + assets). Resolve it from host **`AGENTS.md`** (single-theme: often `.`; multi-theme monorepo: often `src/<theme-id>`). Packages go under **`output/`** (or host-defined pack output):

```bash
# from repo root
/path/to/cdxthemex theme pack theme-dir -o output/theme.cdxtheme --force

/path/to/cdxthemex theme pack theme-dir/theme.json -o output/example-theme.cdxtheme
```

| Flag | Description |
|------|-------------|
| `-o`, `--output` | Output path (default `{id}-{version}.cdxtheme`) |
| `--pretty` | Pretty-print JSON |
| `--force` | Overwrite existing file |

**Source layout**

When packing a directory, the CLI looks for source JSON in this order:

1. `theme.json`
2. `manifest.json` (if `theme.json` is missing)

```text
theme-dir/
  theme.json
  codex/                 # partials (source of truth; edit these)
    00-tokens.css
    01-shell.css
    …
  workbuddy/
    00-tokens.css
    …
  codex.css              # generated by merge-css / pack
  workbuddy.css
  assets/hero.jpg
```

```json
{
  "schemaVersion": 1,
  "id": "example-theme",
  "displayName": "Example",
  "version": 1,
  "copy": { "brandTitle": "…" },
  "targets": {
    "codex": {
      "css": "codex.css",
      "options": {
        "rendererProfile": "codex-theme-v1",
        "baseTheme": { "mode": "dark", "accent": "#DC0000" }
      }
    },
    "workbuddy": { "css": "workbuddy.css" }
  },
  "images": { "hero": "assets/hero.jpg" }
}
```

### `theme merge-css`

Concatenate split CSS partials into the root files declared in `theme.json`.

```bash
/path/to/cdxthemex theme merge-css theme-dir
/path/to/cdxthemex theme merge-css theme-dir -t codex
/path/to/cdxthemex theme merge-css theme-dir --target workbuddy
```

| Input | Output |
| --- | --- |
| `codex/*.css` (alphabetical) | `codex.css` |
| `workbuddy/*.css` | `workbuddy.css` |

- Numeric prefixes (`00-tokens.css`, `01-shell.css`, …) control order.
- Generated files start with a “do not edit by hand” banner.
- **`theme pack` merges partials in memory** into the `.cdxtheme` (does **not** write root `codex.css` / `workbuddy.css`). Skip with `--no-merge-css`. Use `theme merge-css` to materialize root CSS files.
- Prefer editing partials only — see skill **CSS partials** map for which file to open.

### `theme unpack`

```bash
/path/to/cdxthemex theme unpack example-theme-1.0.0.cdxtheme /tmp/example-theme
# → theme.json + codex/theme.css + images/…
```

Accepts `.cdxtheme` packages.

### `apply`

Inject a theme package into a live host app over the /path/to/cdxthemex CLI.


```bash
/path/to/cdxthemex apply --app codex --theme output/example-theme.cdxtheme
/path/to/cdxthemex apply -t ./output/mercedes-f1.cdxtheme --port 9335
```

| Flag | Description |
|------|-------------|
| `--app` | Host app id (currently only `codex`) |
| `-t`, `--theme` | Path to `.cdxtheme` |
| `--port` | CDP port (default `9335`) |
| `--timeout-ms` | Wait / inject timeout (default `120000`) |

### Iteration loop (theme authoring)

After editing theme CSS partials under `theme-dir/codex/` or `workbuddy/`:

```bash
/path/to/cdxthemex theme merge-css theme-dir   # optional; pack auto-merges
/path/to/cdxthemex theme pack theme-dir -o output/<theme-id>.cdxtheme --force
/path/to/cdxthemex apply -t ./output/<theme-id>.cdxtheme
/path/to/cdxthemex verify layout
# optional:
/path/to/cdxthemex verify inject -t output/<theme-id>.cdxtheme
/path/to/cdxthemex probe --tab work
/path/to/cdxthemex screenshot -o /tmp/work.jpg --tab work

# Saved layout probes (hero / util stack / ::before) — see scripts/probe/README.md
/path/to/run.sh go-work-home
/path/to/run.sh work-layout
/path/to/run.sh set-mode chat
/path/to/run.sh chat-layout
```

When changing the composer, re-check **Chat home**, **Work home**, and **conversation detail** (detail needs relative layout; see [codex.md](codex.md)).

## Package JSON

```json
{
  "format": "cdxtheme",
  "schemaVersion": 1,
  "exportedAt": "…",
  "theme": { "id": "…", "displayName": "…", "version": 1, "copy": { } },
  "targets": {
    "codex": {
      "css": "/* inlined */",
      "options": { "rendererProfile": "codex-theme-v1", "baseTheme": { } }
    }
  },
  "assets": {
    "images": {
      "hero": { "filename": "art.png", "mimeType": "image/png", "base64": "…" }
    }
  }
}
```

Max size **30 MB**. Max images **32**. No remote CSS `@import` / `url(http…)`.
